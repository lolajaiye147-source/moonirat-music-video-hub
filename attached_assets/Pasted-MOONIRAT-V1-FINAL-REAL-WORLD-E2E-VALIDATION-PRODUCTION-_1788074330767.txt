MOONIRAT V1 — FINAL REAL-WORLD E2E VALIDATION & PRODUCTION GATE

Moonirat is a creator-first music-video platform serving BOTH:

* Creators / Artists
* Viewers / Fans / Followers

The core V1 loop is:

Upload → Discover → Watch → Follow

Do NOT add new product features during this task.

Do NOT start V1.1.

Do NOT add monetization, ads, AI, comments, microservices, or another database.

The objective is to prove that the existing Moonirat V1 actually works end-to-end with the live Supabase project.

6. REAL VIDEO VALIDATION

This is a critical V1 gate.

Test actual uploaded media.

Verify:

* correct video URL comes from Supabase
* no hardcoded media URL
* player does not depend on stale memoized source state
* direct video playback works
* HLS remains optional if supported
* missing media URL has a graceful error
* invalid media URL has a graceful error
* retry works
* buffering state works
* play/pause works
* seeking works
* fullscreen works
* mobile playback works
* iOS/Safari-compatible behavior is preserved
* player does not crash when video data is temporarily unavailable

Verify that video playback still works after page refresh.
