MOONIRAT V1 — FINAL STABILIZATION & RELEASE-CANDIDATE HARDENING

The Beta Feedback Journey is now complete. Moonirat V1 is entering FINAL STABILIZATION.

This is NOT a feature-development task.

The goal is to turn the existing Moonirat V1 into a stable, secure, production-quality release candidate for a SMALL CONTROLLED BETA.

FIRST: thoroughly inspect the existing repository, current Supabase project integration, migrations, RLS policies, Storage configuration, routes, authentication, Viewer journey, Creator journey, Admin journey, Feedback journey, and all existing certification/gate documents.

Do not assume previous work is correct. Verify it.

SOURCE OF TRUTH:

* Existing Moonirat repository
* Existing Supabase project
* Existing Supabase PostgreSQL
* Existing Supabase Auth
* Existing Supabase Storage
* Existing RLS/security model

DO NOT:

* provision a new database
* introduce Replit Postgres/Drizzle as another production database
* create a second backend
* replace Supabase
* add AI
* add monetization
* add ads
* add comments
* add unnecessary social features
* add microservices
* add speculative infrastructure
* add permanent transcoding/HLS pipelines unless validation proves V1 actually requires them
* introduce mock/demo data
* weaken RLS
* expose service-role credentials
* redesign working features unnecessarily

MOONIRAT V1 REMAINS:
Upload → Discover → Watch → Follow

with viewers, followers, creators, and administrators all treated as first-class users.
