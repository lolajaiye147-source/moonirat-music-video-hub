You are working on the existing Moonirat V1 production codebase.

This is now a P0 blocker. Fix the existing account-creation flow before doing any new features or beta-launch work.

CORE PRODUCT RULE

Moonirat is NOT an artist-only platform.

Every person should be able to create a normal Moonirat account as a:

* Viewer
* Fan
* Follower

An artist/creator profile is OPTIONAL and must be created later.

Therefore:

SIGN UP ≠ CREATE ARTIST PROFILE

The signup screen must NEVER require an artist name or imply that every new user is an artist.

The correct journey is:

Sign Up
→ Moonirat account created
→ Viewer/Fan profile created
→ Email confirmation if enabled
→ User can browse, watch, follow, like, create playlists, and submit feedback
→ Later, user may choose “Become a Creator / Create Artist Profile”
→ Creator onboarding begins only then.
